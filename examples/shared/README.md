# examples/shared

Общий код для примеров `auth-*`: список production-серверов Retouch4me и переключение URL через `OauthAPI.setFullUrl()`.

## Когда это нужно

Используйте этот модуль, если хотите:

- переключать окружения (наборы endpoint URL) из UI примера,
- иметь один и тот же список серверов для нескольких примеров,
- централизованно сбрасывать сессию при смене сервера.

Подключается **относительным импортом** из `src/` каждого примера:

```ts
import { initServerSelect } from "../../shared/oauthStaticServers";
```

Webpack при сборке встраивает этот файл в `dist/index.js` плагина — отдельно в manifest его указывать не нужно.

## Важно при копировании репозитория

Примеры рассчитаны на структуру monorepo:

```
examples/
  shared/
  email-password/
  oauth-browser/
  oauth-rsa-keys/
```

Если выносить один пример в отдельный проект, скопируйте вместе с ним папку `examples/shared/` и сохраните относительный путь `../../shared/` (или скопируйте `oauthStaticServers.ts` в `src/` примера).

Выбор сервера сохраняется в `localStorage` под ключом `selectedServerId` и общий для всех примеров в одном Photoshop.

## Как подключить в своём примере

1. Скопируйте `examples/shared/oauthStaticServers.ts` в проект (или оставьте относительный импорт `../../shared/...` в монорепо).
2. В точке инициализации создайте `OauthAPI` экземпляр.
3. Вызовите `initServerSelect(oauth, onChange)` до первых API-запросов.
4. В `onChange` сбрасывайте локальную сессию пользователя, чтобы не смешивать токены разных окружений.
